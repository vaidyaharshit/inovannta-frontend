# INNOVANTA — Student-Led Innovation Ecosystem

> **MANIFEST. BUILD. IMPACT.**  
> A student-led innovation ecosystem where curious minds collaborate, build meaningful projects, explore emerging technology, and turn ambitious ideas into real-world impact.

---

## 🚀 Overview

**INNOVANTA** is built to empower aspiring innovators, developers, researchers, and entrepreneurs through structured initiatives, multi-disciplinary labs, and venture incubation.

### The Triad of Action
- **Manifest:** Imagine possibilities, identify problems, and envision what can be achieved.
- **Build:** Transform ideas into projects, solutions, and open-source initiatives.
- **Impact:** Create meaningful value for students, campuses, and industry.

### Six Core Pillars
1. **Technology & AI:** Intelligent systems, machine learning architectures, and hands-on technical labs.
2. **Innovation & Projects:** Functional software, hardware prototypes, and open-source ecosystems.
3. **Research & Knowledge:** Academic inquiry, paper reading groups, and collaborative research.
4. **Entrepreneurship & Startups:** Founder frameworks, pitch validation, and early venture incubation.
5. **Events & Community:** Hackathons, technical symposia, and peer-to-peer masterclasses.
6. **Partnerships & Outreach:** Inter-college alliances, industry mentorship, and sponsor collaborations.

## 💻 Getting Started Locally

### Prerequisites
- Node.js (v18 or higher recommended)
- npm / yarn / pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/vaidyaharshit/inovannta-frontend.git

# Navigate to project directory
cd inovannta-frontend

# Install dependencies
npm install
```

### Development Server

```bash
npm run dev
```

Visit `http://localhost:5173/` in your browser.

### Build for Production

```bash
npm run build
```

The compiled output will be generated inside the `dist/` directory.
